# Cult Illusion

**Cult Illusion** — клиентский Fabric-мод для Minecraft, созданный **andryfoxy** для проведения игровых событий, связанных с организацией **«Церковь Вознесения»** на сервере.

Мод добавляет визуальные, звуковые и игровые эффекты, связанные с клинками и силами Церкви Вознесения: ритуалы, церемонии, проявления Безымянного и способности владельцев клинков.

> **Автор проекта: andryfoxy.** Проект создан с использованием инструментов искусственного интеллекта под руководством автора. Использование ИИ как инструмента разработки не отменяет необходимости указывать автора проекта и соблюдать условия лицензии.

## Варианты сборки

В предоставленных исходных проектах находятся две версии:

| Проект | Назначение |
|---|---|
| `cult_illusion_power` | Основная версия: позволяет запускать способности, церемонии и ритуальные события. |
| `cult_illusion_frame` | Observer-версия: отображает события и эффекты, запущенные другими игроками с совместимой версией мода; самостоятельно запускать их не предназначена. |

Не смешивайте JAR-файлы разных вариантов. Устанавливайте вариант, соответствующий роли клиента.

## Основные возможности

В зависимости от версии и настроек мод содержит:

- эффекты и способности, связанные с клинками Власти, Разума, Тени, Шепота и Печати;
- визуальные эффекты: частицы, цепи, метки целей, ауры, иллюзии и экранные искажения;
- звуковое оформление способностей;
- церемонии передачи силы и ритуальные эффекты;
- визуальные и звуковые проявления Безымянного;
- взаимодействие с Simple Voice Chat для отдельных эффектов Печати (если мод голосового чата установлен и совместим).

Точный набор доступных действий зависит от конкретной сборки. Observer-версия предназначена для просмотра событий, а не для их инициирования.

## Техническая информация

По конфигурации приложенных проектов:

- Minecraft: **26.2** (в `fabric.mod.json` также заявлен диапазон `26.2–26.3`);
- загрузчик: **Fabric**;
- Java: **25**;
- Fabric Loader: `0.19.5`;
- Fabric API: `0.161.0+26.2`;
- Simple Voice Chat: необязательная зависимость для соответствующей функциональности.

Мод помечен как клиентский (`environment: client`). Для его установки не требуется отдельный серверный модуль. При этом основная версия передаёт служебные маркеры событий через обычные игровые сообщения чата, чтобы клиенты с модом могли распознать запуск события и показать соответствующие эффекты. Это не означает, что серверная часть мода установлена или что сервером реализуется логика способностей. Сервер может обрабатывать сообщения по своим обычным правилам чата.

## Установка

1. Установите совместимые версии Minecraft, Fabric Loader и Fabric API.
2. Скачайте JAR-файл нужного варианта мода.
3. Поместите JAR в папку `mods` клиента Minecraft.
4. Если требуется функциональность, связанная с голосовым чатом, установите совместимую версию Simple Voice Chat.
5. Запустите игру и проверьте, что мод загружен.

Используйте сборку, соответствующую версии Minecraft и зависимостям, указанным для конкретного релиза.

## Сборка из исходного кода

Для сборки приложенных проектов требуется JDK 25 и Gradle Wrapper (если он включён в исходный архив).

Из корневой папки выбранного проекта выполните:

```bash
./gradlew build
```

В Windows PowerShell:

```powershell
.\gradlew.bat build
```

Готовый JAR обычно находится в `build/libs/`.

Если в архиве отсутствует `gradlew.bat` или `gradlew`, сначала необходимо создать Gradle Wrapper совместимой версии. Не запускайте команду сборки из родительской папки, в которой нет файла Wrapper.
